# Vendor CAD Download List

The following standard-part categories require real manufacturer CAD downloads in later phases:

- Motors
- Linear guide rails
- Carriage blocks / sliders
- Timing belts
- Pulleys
- Lead screw
- Coupling
- Bearing blocks
- Aluminum profiles
- Cable drag chain
- Limit switches
- Sensors
- Emergency stop button
- Electric gripper
- Fasteners

Fallback models may be used temporarily for envelope planning only. Industrial release should replace placeholders with manufacturer CAD or approved simplified supplier geometry.
