# Scan Station Reference Parameters

- File: `scan_station_reference_block.step`

## Purpose

Temporary scan-station reference block for rough assembly. It marks the area where the gripper holds a tube for Panasonic CX-421-J presence detection and Cognex DataMan 80 barcode/QR reading.

## Material Suggestion

- POM or aluminum placeholder material

## Placeholder Status

Placeholder only. It is not a final scan fixture and is not a production drawing.

## Parameters To Freeze Later

- cable routing clearance

No final drawing needed for this reference block. Final scanner/sensor brackets will need drawings.
